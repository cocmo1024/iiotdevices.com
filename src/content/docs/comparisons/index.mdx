## How to use comparisons well

<Steps>
	1. Lock the application and operating problem first.
	2. Define the device boundary and support owner before narrowing products.
	3. Use comparison pages to remove weak fits, not to create architecture from scratch.
	4. Finish by re-checking lifecycle burden, maintenance reality, and rollout simplicity.
</Steps>
